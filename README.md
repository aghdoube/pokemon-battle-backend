# Pokémon Battle Simulation – Node.js Backend Engine

A robust, enterprise-grade Node.js server environment designed to power full Pokémon battle states and simulation engines. This project connects modern web frameworks to multi-tier database systems.

## 🚀 Engine & Database Architecture

- **API Framework:** Deployed utilizing Express to handle high-availability routing loops and CORS policies.
- **Dual-Database Integrations:**
  - **MongoDB (via Mongoose ODM):** Architected to manage unstructured, fluid battle rules, tournament profiles, and individual player logs.
  - **PostgreSQL (via Sequelize ORM):** Implemented to handle strict relational structures like global static stats, attributes, and balancing mechanics.
- **Security & Pipeline Frameworks:** Pre-configured for JWT web token security rules and structured `.env` configuration abstractions.

## 🛠️ Tech Stack

- **Runtime:** Node.js (ES6 Modules)
- **Framework:** Express.js
- **Databases & Drivers:** MongoDB (Mongoose), PostgreSQL (pg, Sequelize)
